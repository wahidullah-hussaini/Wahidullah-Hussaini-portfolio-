# Your images

Put your own photographs here. Never use someone else's photo as yours.
Until a file exists, the website shows a clearly marked placeholder.

| Folder | File name | What it is | Suggested shape |
| --- | --- | --- | --- |
| `profile/` | `profile.jpg` | Main portrait (home page hero) | portrait, about 1200 × 1500 px |
| `profile/` | `about.jpg` | Personal or university photo (About page) | any, about 1600 px wide |
| `gallery/` | `gallery-01.jpg`, `gallery-02.jpg`, ... | Personal gallery | any, about 1600 px on the long side |
| `projects/` | for example `my-site.jpg` | Real project screenshots | 16:10, about 1600 × 1000 px |
| `certificates/` | for example `certificate-name.jpg` | Real certificate scans | any |

Tips:

- Use `.jpg` or `.webp`. Keep each file under about 400 KB (resize large photos first).
- File names are lowercase with no spaces.
- After adding a gallery photo, write its description in `src/data/gallery.js`.
- Folder names and paths are listed in the data files; the site never depends on
  images from other websites.
